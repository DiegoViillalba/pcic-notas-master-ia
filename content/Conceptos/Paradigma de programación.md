# Paradigma de programación

## Definición inicial

Modelo conceptual que orienta cómo expresar el estado, el control y la solución de un problema dentro de un lenguaje.

## Ejemplo mínimo

Para obtener los cuadrados de una lista, un enfoque imperativo actualiza una colección mediante un ciclo; uno funcional aplica una transformación como `map`.
