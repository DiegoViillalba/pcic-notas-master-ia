# Lenguajes compilados

## Definición inicial

Lenguajes cuya implementación traduce el código fuente antes de ejecutarlo, normalmente a código máquina o a una representación intermedia.

## Ejemplo mínimo

Un compilador de C puede producir un ejecutable nativo; `javac` transforma Java en *bytecode* para la JVM.

## Límite

“Compilado” describe una estrategia de implementación, no una propiedad inmutable del lenguaje. Java combina compilación previa y compilación justo a tiempo.
