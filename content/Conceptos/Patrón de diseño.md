# Patrón de diseño

## Definición inicial

Esquema reutilizable que describe el núcleo de una solución para un problema de diseño recurrente dentro de un contexto determinado.

## Ejemplo mínimo

Factory Method separa la solicitud de creación de un objeto de la clase concreta que finalmente se instancia.

## Límite

Un patrón no es código listo para copiar ni garantiza una buena solución. Debe justificarse por el problema y sus consecuencias.

## Familias mencionadas

- Creación.
- Estructurales.
- Comportamiento.
- Sistema o arquitectura.
- Concurrencia.
