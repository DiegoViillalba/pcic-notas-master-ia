# Lenguajes imperativos

## Definición inicial

Lenguajes que describen cómo cambia el estado de un programa mediante instrucciones, asignaciones y estructuras de control.

## Ejemplo mínimo

```text
suma <- 0
para cada x en datos:
    suma <- suma + x
```

La variable `suma` cambia después de cada instrucción.

## Relaciones

- Contrasta con: [[Lenguajes declarativos|Lenguajes declarativos]].
- Se organiza mediante: [[Programación estructurada|Programación estructurada]].
- Ejemplos mencionados: C, Java, Pascal y C++.
